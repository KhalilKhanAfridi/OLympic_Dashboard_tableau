🏅 Olympic Data Analysis Project – From Storytelling to Insights Dashboard 
In this project, I transformed raw data into interactive dashboards and meaningful insights, focusing on both storytelling and exploratory data analysis (EDA).
🔎 Project Highlights:
 📖 Magazine-style storytelling: “The Story of Olympics”
 🌍 Interactive Map visualization
 🥇 Overall & Country-wise Medal Tally
 📊 Dashboard with key metrics:
Total number of athletes
Participating countries
Gender distribution (Pie Chart)
Age distribution (Histogram)
Height vs Weight (Scatter Plot)
 🏆 Top Athletes & Top Sports analysis
 📅 Year-wise medal trends
This project helped me strengthen my skills in data cleaning, visualization, dashboard design, and extracting actionable insights from large datasets.
